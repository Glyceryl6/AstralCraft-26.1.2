# 吉星工艺

## 📖 简介

**吉星工艺** 是一个以《吉星派对》（Astral Party）为主题的 Minecraft 趣味模组。本模组将游戏《吉星派对》中的部分玩法给还原到了MC中，包括但不限于各种手牌、地块、筹码、Buff等，旨在让玩家在MC中也能体验到玩星趴的乐趣。后续我们还会开发出更多的玩法，敬请期待！如果您还觉得不错的话，那就……关注星趴谢谢喵~❤️
